2. BACKEND ROUTING & WORKSPACE HANDLERS
--------------------------------------------------------------------------------
- ToolCatalog & ExtensionCatalog (App/Services/Mobile & App/Extensions/MagicaiMobile):
  * Registered built-in tool definitions for `ai_plagiarism`, `ai_content_detect`, and `ai_article_wizard_generator`.
  * Bound dedicated native tool schemas with inputs, tokens, and response contracts.
- NativeScreenService:
  * Mapped exact `routeType()` for all 33 tools so none fall through to web scraping.
- NativeWorkspaceService:
  * Added kind() resolution for: `team`, `api_keys`, `affiliates`, `integration`, `ai_influencer`, `ai_persona`, `video_studio`, `video_pro`, `video_agent`, `auto_edit`, `product_shot`, `presentation`, `ai_avatar`, `image_pro`, `viral_clips`.
  * Implemented query methods with real Eloquent queries and KPI metric cards.
  * Implemented mutation handlers for:
    - Team: invite member (validates email & role, sends SendTeamInviteEmail), delete member.
    - API Keys: save custom OpenAI, Claude, and Gemini API keys.
    - Affiliates: request payout (validates available balance, logs UserAffiliate), send partner invite.
    - Integrations: connect/disconnect credentials.
    - Media outputs: delete record across UserFall, VideoAgentVideo, AutoEditRender, UserPebblely, AiPresentation, AiAvatar, AiImageProModel, ExportedVideo.
- Rate Limiting:
  * Upgraded /mobile/open/{ticket} throttle from 20 req/min to 120 req/min to prevent 429 Too Many Requests during rapid module exploration.
