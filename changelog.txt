2. CRM COMPANIES MODULE FIX (https://ai.zoomnearby.com/dashboard/user/crm/companies)
--------------------------------------------------------------------------------
[PROBLEM STATEMENT]
  When navigating to the CRM Companies workspace in the mobile app, the screen
  failed to display company records and raised:
  "Unable to load this workspace. Please retry."

[ROOT CAUSE ANALYSIS]
  1. Backend Response Nesting:
     In app/Services/Mobile/NativeWorkspaceService.php:
     'companies' => ['data' => $this->companies($user, $data)],
     Because $this->companies() already calls $this->page(), which returns
     ['data' => $records, 'current_page' => ..., 'last_page' => ..., 'total' => ...],
     wrapping it in an extra ['data' => ...] caused the workspace payload to have
     an associative Map under 'data' instead of a List:
     {"data": {"data": [...], "current_page": 1, ...}}
  2. Flutter Strict Type Assertion:
     In lib/services/native_workspace_service.dart:
     data['data'] is! List threw an ApiFailure exception when encountering the
     nested Map structure.
  3. Route Type Mapping:
     In app/Services/Mobile/NativeScreenService.php:
     dashboard.user.crm.companies.index was missing an explicit route mapping,
     falling back to 'schema'.
  4. Flutter Module Registry:
     In lib/screens/native_module_screen.dart:
     'companies' route type was not explicitly registered in the module switch.

[IMPLEMENTED SOLUTIONS]
  1. Backend (NativeWorkspaceService.php & MagicaiMobile/System/Services/NativeWorkspaceService.php):
     - Changed 'companies' => ['data' => $this->companies($user, $data)]
       to 'companies' => $this->companies($user, $data).
     - Changed 'campaigns' => ['data' => $this->campaigns($user, $data)]
       to 'campaigns' => $this->campaigns($user, $data).
     - Verified via Artisan Tinker: $service->view() now returns 'data' as a flat
       JSON array (List) containing company records (e.g., Zoomnearby Network).
  2. Backend Route Registry (NativeScreenService.php & MagicaiMobile/System/Services/NativeScreenService.php):
     - Added explicit route match:
       $route === 'dashboard.user.crm.companies.index' => 'companies'
  3. Flutter Workspace Service (lib/services/native_workspace_service.dart):
     - Added robust normalization in NativeWorkspaceService.load():
       If 'data' is a Map (nested from legacy or unpatched servers), it automatically
       extracts rawData['data'] as the list and extracts pagination metadata.
       If 'data' is already a List, it uses it directly.
       Guarantees 'data' and 'modules' are always valid Lists.
  4. Flutter Workspace Screen (lib/screens/native_workspace_screen.dart):
     - Enhanced _NativeWorkspaceScreenState._load() to safely flatten records
       regardless of top-level or nested response structure.
     - Full support for Company listing, search filter, creation ('New company'),
       editing, and deletion confirmed active.
  5. Flutter Module Registry (lib/screens/native_module_screen.dart):
     - Added 'companies' => NativeWorkspaceScreen(module: module, api: client).


3. SALES TOOLS FULL PARITY (INVOICES, PAYMENTS, PROPOSALS, ESTIMATES)
--------------------------------------------------------------------------------
[FEATURE 1] Sales Invoices (dashboard/user/sales/invoices)
  - Native "Create invoice" button in page header and empty state.
  - Full modal creation/editing form with auto-generated document numbers (INV-xxxxx),
    currency selection, customer company dropdown, contact dropdown, deal dropdown,
    status selector (draft, sent, paid, cancelled), issue date & due date pickers,
    and multiline notes.
  - Integrated card action menu:
    * "Record payment": opens payment recording pre-filled with invoice ID, customer,
      balance due, and currency.
    * "Edit invoice": edit total amount, dates, contact/company, and status.
    * "Delete invoice": confirmation dialog with real invoice identifier.
  - KPI summary cards: Total Invoiced, Outstanding Balance, Paid, and Overdue.
  - Status filter chips: All invoices, Draft, Sent, Paid, Overdue.

[FEATURE 2] Sales Payments (dashboard/user/sales/payments)
  - Native "Record payment" button in page header.
  - Record payment form supporting:
    * Link to Sales Invoice.
    * Payment amount with decimal validation.
    * Currency selector.
    * Payment method (Bank Transfer, Credit Card, Cash, PayPal, Stripe, Other).
    * Status (Completed, Pending, Failed, Refunded).
    * Transaction / Reference ID.
    * Payment date picker.
    * Customer company and contact association.
    * Payment notes.
  - Automatic invoice reconciliation: Recording a completed payment updates invoice
    paid amounts and auto-advances invoice status ('paid' or 'partial').

[FEATURE 3] Sales Proposals (dashboard/user/sales/proposals)
  - Native "Create proposal" action, auto-numbered (PROP-xxxxx), client company/contact
    pickers, deal association, proposal date & valid-until date pickers, notes.

[FEATURE 4] Sales Estimates (dashboard/user/sales/estimates)
  - Native "Create estimate" action, auto-numbered (EST-xxxxx), company/contact/deal
    pickers, estimated amount, estimate & expiry date pickers.
