0. SOCIAL MEDIA AGENT POST INTEGRITY & AUTO-PROVISIONING FIX
--------------------------------------------------------------------------------
- Resolved SQL Integrity constraint violation (1048 Column 'agent_id' cannot be null):
  * Cause: When creating/saving a social post without an explicitly selected agent/platform (or when a user has no pre-configured social agents or platforms), `agent_id` and `platform_id` evaluated to `null`, violating foreign key constraints on `ext_social_media_agent_posts`.
  * Auto-Provisioning & Self-Healing:
    - Backend automatically provisions a default `SocialMediaPlatform` (e.g. 'x') and `SocialMediaAgent` with linked platform IDs if none exist for the user.
    - Fallback assignment on `save`, `duplicate`, and `publish` ensures posts always have valid foreign keys.
    - Post `content` safely defaults to non-empty string and `status` to valid enum values.
  * Flutter App UI Pre-Selection:
    - Form editor in `native_workspace_screen.dart` pre-selects the first available platform and agent from lookups.
    - Platform and Agent dropdowns enforce selection (`allowClear: false`) to prevent accidental null submissions.
  * Mobile App Backend Connector Installer Updated:
    - Rebuilt complete customer package and single-file browser installer: `/magicai-mobile-install.php` (443 KB).
    - URL: https://ai.zoomnearby.com/magicai-mobile-install.php
    - SHA256: `aa92362b391f3e361646e6f97ea6cdfb696f87a9aa2138df655111decc1d91ca`
    - Bundles all latest API endpoints, self-healing social media agent constraints, Web API key parity, and workspace handlers for client MagicAI installations.
