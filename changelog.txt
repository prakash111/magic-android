1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
This release establishes 100% full feature parity between the MagicAI Web Phone
Call Agent module (https://ai.zoomnearby.com/dashboard/phone-call-agent) and the
Flutter mobile app across all Phone Call Agent tools and workflows:

  1. Phone Call Agent Dashboard & Overview (dashboard.phone-call-agent.index):
     - Interactive 3-tab navigation matching web: "Agents", "Call History", "Outbound".
     - Real KPI stat cards: Total Agents, Active Agents, Today's Calls, Outbound Calls.
     - Gradient Hero banner with quick action buttons: "Create New Agent", "Call History", and "Outbound Calls".
     - Real-time live search filter by agent title, phone number, or prompt instructions.
     - Agent cards with provider badges (ElevenLabs / Twilio), attached phone numbers, voice names, today's call counter, and active status indicator.
     - 1-tap live Active switcher (optimistic UI update with live backend toggle).
     - Direct "Test Call" action launching realistic mobile Call Simulator.
     - Agent options dropdown: "Configure", "Train Knowledge", "Phone Numbers", "Test Simulator", and "Delete Agent".

  2. Agent Creation & Configuration Wizard (dashboard.phone-call-agent.new / store / update):
     - 3-step wizard with step pills: "1. Configure", "2. Train", "3. Phone Numbers".
     - Step 1 (Configure): Agent title, initial welcome message, instructions (system prompt), language selector, AI model selector (gpt-4o-mini, gpt-4o, claude-3-haiku), max call duration (sec), silence timeout (sec), active switch, and booking assistant integration (Cal.com / Calendly, event type URI, API key, timezone).
     - ElevenLabs Voice Selection: searchable voices list with category, language tags, and instant audio sample preview playback simulation.
     - Step 2 (Train Knowledge Base): URL, Text, and File knowledge management with embedding status chips and delete actions.
     - Step 3 (Phone Numbers): View attached phone number, connect/import new Twilio/SIP/Exotel numbers, and release phone number.

  3. Phone Call Simulator (phone-simulator.blade.php):
     - Mobile phone mockup modal supporting live agent test simulation.
     - State progression: Ready to Call -> Connecting... -> Connected & In-Call with active pulse animation and mm:ss timer -> End Call -> Call Ended summary.
     - Binds to backend /simulate mutation to generate signed conversation session.

  4. Call History & Turn-by-Turn Transcripts (dashboard.phone-call-agent.history / calls):
     - Search calls by caller or called phone number.
     - Status filter chips: All, Completed, Busy, No-Answer, Failed.
     - Direction filter chips: All, Inbound, Outbound.
     - Call cards displaying caller/called numbers, agent title, duration (formatted mm:ss), direction arrow, status badge, and pinned indicator.
     - Interactive Call Detail bottom sheet with turn-by-turn chat bubbles (Agent vs Caller messages), pin/unpin call action, and delete call action.

  5. Outbound Calling & Campaigns (dashboard.phone-call-agent.outbound.index / calls / campaigns):
     - "Place a Call" bottom sheet: select agent with phone number, enter recipient phone number in E.164 format, optional schedule datetime, and place call immediately or queued.
     - "New Campaign" bottom sheet: select agent, campaign name, batch recipient phone numbers list, and dispatch campaign.
     - Outbound campaigns feed showing campaign status, completed/total progress indicator, and recipient counts.
     - Paginated outbound calls list with status chips and durations.


2. TECHNICAL ARCHITECTURE & BACKEND CONNECTOR
--------------------------------------------------------------------------------
[BACKEND SERVICES & CONNECTORS]
  1. app/Services/Mobile/NativeScreenService.php:
     - Mapped 'dashboard.phone-call-agent.*' and 'dashboard.phone-call-agent.index' directly to 'phone_agent' route type.
  2. app/Services/Mobile/NativeWorkspaceService.php:
     - Added 'phone_agent' workspace kind in view() and kind() dispatcher.
     - Implemented phoneAgent() providing:
       * Metrics: Total Agents, Active Agents, Today's Calls, Outbound Calls.
       * Agents list with today_calls_count, total_calls_count, voice_name, provider.
       * ElevenLabs & Polly voice catalog with audio preview URLs.
       * Call history pagination with transcripts and pinned sorting.
       * Outbound calls, campaigns, and eligible caller agents.
       * Knowledge base training records.
     - Added comprehensive mutate() handler for kinds:
       * 'phone_agent' / 'agent': save (create/update agent + ElevenLabs sync), delete, toggle_active, simulate.
       * 'call': delete, pin, place_call (create call + dispatch PlaceOutboundCallJob).
       * 'campaign': save_campaign (batch recipient creation).
       * 'train': train knowledge base and delete.
       * 'phone_number': attach and release phone numbers.
  3. distribution / magicai-mobile-install.php:
     - Rebuilt and synced customer package installer containing updated NativeWorkspaceService and NativeScreenService.

[FLUTTER MOBILE CLIENT]
  1. lib/screens/native_phone_agent_screen.dart:
     - Dedicated NativePhoneAgentScreen with 3-tab layout, Hero banner, KPI cards, agent cards, status toggles, Call Simulator, Call History with transcripts, and Outbound call/campaign wizards.
  2. lib/screens/native_module_screen.dart:
     - Registered 'phone_agent' => NativePhoneAgentScreen in NativeModuleRegistry.
  3. lib/screens/native_workspace_screen.dart:
     - Dispatches kind == 'phone_agent' directly to NativePhoneAgentScreen.
  4. lib/services/native_workspace_service.dart:
